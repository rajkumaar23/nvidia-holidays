Under the Hood

Always current, zero maintenance

01 — Scrape

Daily GitHub Actions cron

A small Go program fetches NVIDIA's time-off page and parses every YYYY Holidays and Free Days section. Failures leave the last good feed untouched.

02 — Publish

RFC 5545 ICS, deterministic output

Events are all-day, transparent, colour-coded, with stable UIDs — so clients update in place instead of duplicating entries.

03 — Subscribe

Your calendar refreshes itself

Subscribe once. The feed advertises a 12-hour refresh TTL, so new Free Days appear without you doing anything.
